Sumika 快速上手

Sumika 是一个阅读器，不带任何书库或内容源。你用自己喜欢的漫画源或本地文件来填充书架——这也是它无广告、无追踪的原因。

1. 进入书架

首次启动会引导你选择存储目录。选一个专用文件夹用于存放章节下载和备份。之后随时可在 Settings → Data and storage 更改。

2. 添加内容源

进入 Browse → Sources，安装你需要的社区扩展。Sumika 兼容 Mihon/Tachiyomi 生态的扩展格式，并按语言自动过滤。想快速起步？直接把漫画图片或压缩包放进你的文件夹，用 Local source 阅读即可——零配置。

3. 从旧阅读器迁移

如果你在用 Tachiyomi / Mihon：先在那边导出 .tachibk 备份，然后在 Sumika 打开 Settings → Data → Restore backup 选择该文件。书架、阅读进度和分类会一并导入。

4. 下载与离线阅读

在漫画详情页点击下载按钮即可缓存章节。Settings → Data and storage 里可设置存储预算，避免占用过多空间。下载内容完全保存在本机。

5. 隐私与家长模式

Privacy Ledger（隐私台账）：在 Settings → Privacy Ledger 可查看应用实际访问过的每一个网络域名、次数和时间戳，并可导出 CSV。遥测在构建层硬关闭。

家长模式：在 Settings → Browse 开启后强制仅显示 SAFE 内容，并用 PIN / 生物识别锁定。

6. 阅读器手势

阅读器提供多种模式（分页、竖滑、RTL 等），点击屏幕中央唤出工具栏。工具栏上的翻译按钮可调用端侧 AI 翻译，首次使用会下载离线模型，全程不上传图片。
