Install

  1. Open the downloaded .apk file.
  2. Allow Install unknown apps for your browser/file manager when Android asks.
  3. Launch Sumika and pick a storage folder — that's it.

Sumika contains no books or sources by default. Add community sources or drop local manga files into your folder to start reading. See the quick start guide.
