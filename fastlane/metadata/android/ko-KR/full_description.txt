Sumika는 서재를 완전히 통제하고 싶은 독자를 위한 무료 오픈소스 만화 리더입니다. 광고 없음. 추적 없음. 구독 없음.

<b>당신의 서재, 당신의 방식</b>
• 확장 시스템으로 수백 개의 커뮤니티 소스를 탐색하거나 CBZ/ZIP/CBR 파일을 바로 읽기
• 카테고리, 필터, 스마트 정렬로 방대한 컬렉션도 깔끔하게
• 연재 자동 업데이트로 최신 화를 놓치지 않기
• 휴대용 백업(.tachibk 호환) — Tachiyomi, Mihon에서 원탭 이전

<b>만화를 위해 만든 리더</b>
• RTL, LTR, 세로 스크롤(웹툰), 페이지 넘김 등 다양한 읽기 모드
• 작품별 개별 설정: 읽기 모드, 페이지 맞춤, 배경색 등
• 챕터를 다운로드해 완전 오프라인 감상
• Material 3 UI, 폰·태블릿·폴더블 최적화

<b>프라이버시 최우선</b>
• 광고·분석 SDK 미포함 — 텔레메트리는 빌드 수준에서 비활성화(재활성화 불가)
• 프라이버시 레저: 앱의 네트워크 활동을 기기 내에 기록하고 언제든 확인 가능
• 자녀 보호 모드: 성인 콘텐츠 숨김 + 인증으로 설정 잠금
• 기기에 연결된 폴더나 클라우드 스토리지로 백업, 계정 불필요

<b>연재 팔로우</b>
• AniList, MyAnimeList, Kitsu, Shikimori 연동
• 서재별 업데이트 일정과 알림

Sumika는 70개 이상의 언어를 지원하며 GPL-3.0 라이선스로 배포되는 자원봉사자 기반 프로젝트입니다. Sumika 자체는 콘텐츠를 호스팅하지 않습니다. 소스는 직접 선택하여 설치하시며, 거주 지역의 법률과 저작권자 약관을 준수해야 합니다.
